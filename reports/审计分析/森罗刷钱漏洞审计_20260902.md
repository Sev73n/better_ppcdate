# 森罗物语「刷钱」漏洞审计（2026-09-02）

> 基线：`releases/20260828_17.txt`（2320 条）。配方来源：KaleidoscopeCookery / KaleidoscopeTavern 仓库 `src/generated/resources/.../recipes`（367 种产出）。
> 审计脚本：`_tmp_audit.py`（原版合成/熔炼成本表 + 固定点迭代），结果明细：`_tmp_audit_result.json`。

## 用户反馈的问题：水龙头（kaleidoscope_tavern:tap）

- 商店行：count=16，买 222.72 / 卖 139.2 → 单价 **买 13.92 / 卖（收购）8.70**
- 配方：`1× 拉杆 + 1× 漏斗 → 1× 水龙头`（crafting_shaped）
- 定价模型的账：漏斗 7.20 + 拉杆 0.05 = 7.25 → 卖价 7.25×1.2 = 8.70 ✓（与线上值吻合）
- 玩家的账：漏斗可自制 = 5 铁锭(1.00) + 1 箱子(0.20) = **5.20**（铁锭还能用铁矿 0.80 熔炼压到 ≈0.86/个 → 漏斗 ≈4.5）；拉杆自制 ≈0.04
  → 真实成本 ≈ **4.37**，卖回 8.70，**每只净赚 4.34（利润率 99%）** → 刷钱成立。

## 根因（三层）

1. **配方法的成本口径是"商店买价"，不是"玩家最低获取成本"。**
   `reanchor_kaleido.py` 的固定点迭代只覆盖森罗两模组的产物；原版中间件（漏斗/灯笼/链条/梯子/金苹果…）一律取 `shop[物品]` 买价，从不与"自制成本"取低。
2. **原版锚点价本身就是"材料×人工档"的虚高价，卖价又按 0.625 挂在买价上。**
   全店共 **110 项**原版可合成物「商店买价 > 自制成本」，最严重：
   | 物品 | 商店买价 | 自制成本 | 倍率 |
   |---|---:|---:|---:|
   | 灯笼 / 灵魂灯笼 | 5.00 / 5.20 | 0.89 / 0.90 | 5.6× |
   | 漏斗 | 7.20 | 4.35 | 1.7× |
   | 梯子 | 0.07 | 0.006 | 11.7× |
   | 箱子 | 0.20 | 0.04 | 5× |
   | 金苹果 | 42.00 | 32.75 | 1.3× |
   | 末地烛 | 2.20 | 0.52 | 4.3× |
   铁链、桶、末影之眼、闪烁西瓜、金胡萝卜、营火、磨石、堆肥桶、玻璃瓶、各类熟食等同理。
3. **画作等"保留项"完全脱离配方法。** `KEEP` 名单保留收藏价（买 300 / 卖 187.5），但画作实际可合成（`展示框 + 染料`，成本 0.24~10）。

虚高的成本被 ×1.2 加工税放大后写进卖价 → 卖价 > 玩家真实成本 → 刷钱。

## 全量扫描结果

判定口径：`实际利润 = 卖价 − 真实最低成本`；其中等于 20% 加工税的部分为**设计内激励**（用户已拍板），超出部分才是漏洞。

- 卖价 > 真实成本的森罗条目共 **222** 条：
  - **真漏洞 148 条**（利润 > 20% 设计值），超额利润合计 ≈ **2643 金币/轮**
  - 设计内 20% 利润 74 条（如乌龙茶 60.2→72.0、炼金午餐袋 501→601.2，模型成本核算正确，非漏洞）

## 修复建议

1. **画作（最急）**：卖价 187.5 → `成本×1.2 ≈ 0.3~12.2`，或干脆卖价归 0（按刷怪蛋"收藏品不可回收"哲学，买 300 保留）。
2. **修成本模型（治本）**：把原版合成/熔炼表并入配方法固定点迭代——所有材料成本取 `min(商店买价, 自制成本)`；铁锭/金锭等同时挂矿石熔炼路径。重跑森罗重锚即可自动收敛。
3. **原版锚点加硬约束**：对可合成原版物品，`卖价 ≤ 真实合成成本`（否则直接刷钱）；重灾户灯笼/灵魂灯笼/梯子/箱子/末地烛优先。
4. **校验门新增不变量**：`validate` 增加"全店 卖价 ≤ 玩家最低获取成本"扫描（本次 `_tmp_audit.py` 可直接复用为常规审计）。
5. 保留 20% 加工税设计不动——本次漏洞全部来自成本虚高，与"做菜 20% 利润"激励无关。
