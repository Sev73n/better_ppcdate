## 二、定价体系要点（已在 20260827_10 落地）

### 背景事实（用户拍板）
- 服务器默认 **30 倍连锁挖掘**；**时运不叠加**；连锁不增加发现概率，只省采集时间
- → 矿石按"矿脉平均块数"折价：钻石 5 倍、红石/青金石 10 倍、煤 15 倍
- 全局常量：在线 **0.1/分**（添头）、开局 **7**、死亡扣 **10**、最低价 0.01、两位小数
- 回收率分四类：**量产地板块（石/泥/沙/下界岩等）固定 0.01/堆**｜**连锁矿石/材料 5%**｜**不可连锁/合成品/生肉/药水/附魔书 0.625**｜**绿宝石、刷怪蛋、刷怪笼 0**

### 锚点（买价/单块；堆价 = ×64）
圆石 **0.01**｜煤 0.50｜铜锭 0.80｜铁锭 **1.00**｜红石 2.00｜青金石 2.50｜金锭 **5.00**｜钻石 **10.00**｜石英 0.15｜绿宝石 1.00｜下界金矿 4.00｜远古残骸 900｜合金碎片 1080｜合金锭 4500｜鞘翅 13140（后四项"保持"）

### 换算与阶梯
- 熔炼矿 = 锭×0.8（铁矿 0.80/金矿 4.00/铜矿 0.64）；1:1 掉落矿 = 成品；红石矿 = 4×红石 = 8；青金矿 = 6×青金 = 15；金粒 = 金锭/9 ≈ 0.56
- 矿物块 = 9×锭×1.1（钻石块 99；石英块 = **4 石英合成** → 0.70，勿按 9 合 1 算）
- 工具 = max(材料×1.5, 地板)：木 0.30 / 石 0.50 / 铁 4.50 / 金 7.50（金工具垃圾，用地板值）/ 钻石 45 / 合金 4800~5200（保持）
- 装备 = 材料×1.5：皮 1.0/1.5/1.2/0.8；铁 7.5/12/10.5/6；锁链 = 2×铁 = 15/24/21/12；金 37.5/60/52.5/30；钻石 75/120/105/60；合金保持
- 建筑块：材料基底 × 形式系数（台阶 0.55 / 楼梯 1.5 / 墙 1.2 / 栅栏 1.2 / 栅栏门 1.5 / 门 2.5 / 活板门 2.0）；按钮/压力板为显式价（石 0.05、木 0.02）
- 食物村民锚（绿宝石=1.0 反推）：小麦 0.05、胡萝卜/土豆 0.04、甜菜 0.07、南瓜 0.17、面包 0.17、苹果 0.25、曲奇 0.17、蛋糕 1.0；金胡萝卜/闪烁西瓜按**配方成本** 4.5/4.6（用户拍板，不迁就村民价）
- 怪物掉落：有村民锚用村民锚（腐肉 0.03、线 0.05、皮革 0.167、羊毛 0.06、末影珍珠 4.0、鞍 6、命名牌 20、钟 36…），无则努力档（骨头 0.05、火药 0.10、烈焰棒 2、恶魂之泪 5、潜影壳 8、图腾 100、下界之星 500、信标 550、三叉戟 150、锤 110）
